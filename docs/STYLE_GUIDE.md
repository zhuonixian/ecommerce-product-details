# 固定视觉规范

## 1. 视觉定位

整体定位为“高原特产 / 自然原料 / 匠心加工 / 高品质伴手礼”。画面强调真实食品质感和产地故事，不做廉价促销海报。

## 2. 画布与网格

- 画布：1080 × 1920，9:16。
- 页面安全边距：左右至少 48 px，顶部至少 48 px，底部至少 50 px。
- 主标题建议 54–76 px；副标题 22–30 px；正文 20–29 px。
- 每页右上角固定页码 `01 / 06` 至 `06 / 06`。
- 内容卡片使用 18–32 px 圆角、轻阴影和金色细描边。

## 3. 色彩系统

- 深色信息层：深棕、墨绿、酒红或深青，透明度约 85%–95%。
- 内容卡片：暖米白，避免纯白造成突兀。
- 强调色：低饱和金色，用于分割线、序号、描边和小标题。
- 食品主体保持自然颜色，不使用荧光色和过度 HDR。

品类建议：

| 品类 | 主色 |
| --- | --- |
| 青稞烘焙 | 墨绿、青灰、麦金 |
| 牦牛肉制品 | 黑棕、草原绿、金色 |
| 奶茶冲饮 | 深棕、奶油色、暖金 |
| 桑葚果干 | 深紫红、莓果色、暖金 |
| 红枣核桃 | 枣红、胡桃棕、暖金 |
| 枸杞 | 朱红、米白、晴空蓝 |

## 4. 摄影与生成底图

- 写实商业食品摄影，原料纹理清楚，避免塑料感。
- 使用侧逆光或柔和窗光，主体与背景有明确景深。
- 上半部预留标题区域，下半部或中下部放食品主体。
- 产地图可加入草原、果园、高原或田野，但不得伪造具体地标。
- 加工页底图只表达工艺氛围，必须配“工艺图片仅为说明，以真实生产为准”。
- 生成提示词必须明确：`no text, no logo, no watermark, no price, no packaging`。

## 5. 六页固定叙事

1. 商品首屏：商品名、核心风味、三枚卖点、真实包装。
2. 产地与原料：产区氛围、核心原料、三项原料特点。
3. 加工工艺：四步流程，避免写资料未支持的精确温度或时长。
4. 细节与口感：包装原图、四项口感或形态说明。
5. 规格与营养：真实规格、类别、口味、包装方式、营养免责声明。
6. 食用场景：四种适用场景或吃法，文字短、画面强。

## 6. 文案口径

- 推荐：甄选、谷香、枣香、酥脆、软糯、醇厚、方便携带、适合分享。
- 谨慎：高蛋白、低脂、膳食纤维、花青素等，只能在资料支持时使用。
- 禁止：治疗疾病、稳定血糖、降低胆固醇、提高免疫力等功效保证。
- 营养页固定提示：具体配料、营养成分、生产日期、保质期及保存条件，以实物包装为准。
