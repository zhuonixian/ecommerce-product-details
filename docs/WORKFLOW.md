# 商品详情页完整工作流

## 阶段一：资料解析

1. 使用 PDF 文本提取获取商品表格信息。
2. 渲染 PDF 页面核对表格行、包装照片和文字位置。
3. 提取内嵌图片；若图片被扁平化，则从高分辨率页面裁切。
4. 建立商品清单：名称、规格、口味、类别、介绍、包装图路径。
5. 对 PDF 介绍中的功效性语句做合规收敛。

## 阶段二：内容规划

每款生成六页脚本，先确定：

- 首屏核心卖点和三枚短标签。
- 原料页的一句主叙事与三项特点。
- 四步加工流程。
- 四项外观、风味或口感特点。
- 五行规格信息和营养免责声明。
- 四个食用场景。

文案应尽量短，避免整段复制 PDF 介绍。

## 阶段三：场景底图生成

每款至少生成一张高质量 9:16 主场景图。提示词包含：用途、主体、背景、构图、光线、颜色、材质和禁止项。底图不直接生成中文排版，避免错字。

## 阶段四：程序排版

使用 Pillow 完成：

- 背景适配、模糊和渐变遮罩。
- 真实包装照片卡片。
- 标题、副标题、卖点胶囊、信息卡片和页码。
- 六页 PNG、全套预览和纵向长图。
- 单品 ZIP 与批次 ZIP。

中文字体必须先检查所需字形。若 PDF 内嵌字体是子集字体，新增文案可能缺字，应优先使用完整授权中文字体。

## 阶段五：自动验证

- 图片数量是否等于 `商品数 × 6`。
- 每张图片是否为 1080 × 1920。
- PNG 是否可完整解码。
- ZIP `testzip()` 是否返回空。
- 文件中是否残留 `.tmp`。
- 渲染文案是否出现价格、货币符号或促销信息。

## 阶段六：视觉验收

通过批次总览一次查看全部商品，重点检查：

- 标题是否清楚，包装是否足够大。
- 卡片与背景的对比度是否足够。
- 长标题是否缩放得过小。
- 生成底图是否出现伪文字、畸形食物或不合适的品牌元素。
- 规格是否和 PDF、包装一致。
