# 电商商品详情页生成项目

基于商品 PDF、真实包装图片和视觉参考图，批量生成统一风格的 9:16 电商详情页。

## 当前成果

- 已完成 11 款商品，共 66 张详情页图片。
- 每款固定 6 张：商品首屏、产地与原料、加工工艺、细节与口感、规格与营养、食用场景。
- 仓库展示版：1080 × 1920 高质量 JPEG，9:16。
- 原始交付版：1080 × 1920 PNG，保存在完整项目交付包中。
- 所有宣传图均不展示价格，也不放置价格相关提示。
- 商品包装使用资料中的真实图片；场景底图由图像生成模型创建，中文与规格由程序后期排版。

## 固定规则

1. 单个商品固定生成 6 张图片。
2. 画布固定 1080 × 1920，比例 9:16。
3. 生成底图禁止出现文字、Logo、水印、包装和价格。
4. 真实商品包装由程序后期嵌入，不让模型重绘。
5. 图片中禁止出现售价、折扣、货币符号及价格提示语。
6. 不虚构营养数值、认证、检测结果和医疗功效。
7. 配料、营养成分、日期、保质期和保存条件以实物包装为准。

## 快速复用

1. 从商品资料中确认名称、类别、规格、口味、介绍和包装图。
2. 按 `docs/STYLE_GUIDE.md` 生成无文字、无包装、无价格的食品场景底图。
3. 在商品配置中填写真实规格与收敛后的宣传文案。
4. 运行排版脚本生成六页图片、联系表、长图和 ZIP。
5. 检查尺寸、完整性、文字遮挡、包装一致性、价格字段和营养合规性。

依赖：Python 3、Pillow、fontTools。中文字体文件需由运行环境提供。
