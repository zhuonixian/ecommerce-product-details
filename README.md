# 电商商品详情页生成项目

基于商品 PDF、真实包装图片和视觉参考图，批量生成统一风格的 9:16 电商详情页。

## 当前成果

- 已完成 11 款商品，共 66 张详情页图片。
- 每款固定 6 张：商品首屏、产地与原料、加工工艺、细节与口感、规格与营养、食用场景。
- 单张尺寸：1080 × 1920，PNG，9:16。
- 所有宣传图均不展示价格，也不放置“以商家价格为准”等价格相关提示。
- 商品包装使用 PDF 中的真实图片；场景底图由图像生成模型创建，中文与规格由程序后期排版。

## 快速复用

1. 从 PDF 中确认商品名称、类别、规格、口味、介绍和包装图。
2. 按 `docs/STYLE_GUIDE.md` 生成无文字、无包装、无价格的食品场景底图。
3. 在商品配置中填写真实规格与经过收敛的宣传文案。
4. 运行排版脚本生成 6 张 PNG、预览长图和 ZIP。
5. 检查尺寸、图片完整性、文字遮挡、包装一致性、价格字段和营养合规性。

依赖：Python 3、Pillow、fontTools；中文字体文件需由运行环境提供。

## 重要说明

- 包装上的品牌、净含量等属于商品原图内容，应保留。
- PDF 中的报价只用于业务参考，不进入宣传图。
- 配料、营养数值、生产日期、保质期和储存方式以实物包装或正式资料为准。
- “低GI”“无糖”等声明只有在商品包装或有效资料明确支持时才可展示。
